# Weapon Switch Queue

Client-only. Press a hotbar weapon while mid-swing and it equips when the attack animation finishes. A queued switch still applies while sprinting. Optional: queue sheath (Hide) the same way.

Replaces **Queue Me Maybe** for this pack (same idea, maintained GUID for cjayride).

Config: `BepInEx/config/cjayride.weaponswitchqueue.cfg`
