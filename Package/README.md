# Weapon Switch Queue

Client-only. Hotbar weapon presses during an attack are remembered and applied when the swing finishes. Sheath (Hide) can be queued too.

**Install:** `BepInEx/plugins/cjayride-WeaponSwitchQueue/Cjayride.WeaponSwitchQueue.dll`

**Not the same as Hotbar Switch** — that mod only cycles which inventory row is treated as the hotbar.
